# Example: Sample Application Bundle

This folder contains a sanitized example of a complete application bundle — the files produced during a single application workflow.

**All names, companies, and content are fictional. This is for reference only.**

---

## Files in This Bundle

| File | Description |
|------|-------------|
| `jd_sample.txt` | The job description that was used |
| `gap_analysis_sample.md` | Gap analysis output |
| `resume_draft_sample.md` | Resume draft before export |
| `cover_letter_sample.md` | Cover letter draft |
| `log_entry_sample.csv` | The log row written after submission |

---

## How to Use This Example

1. Read through the files in order to understand the pipeline output format
2. Compare your own gap analysis and resume drafts against this example
3. Use as a reference when setting up your profile_knowledge_base/

## Note on Authenticity

This example uses fictional data. The quality of your actual outputs depends entirely on the depth and accuracy of your profile_knowledge_base/ content. The more specific and complete your profile, the better the AI's output will be.
